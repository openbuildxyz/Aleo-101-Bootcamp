# 技术规范

Aleo 提供了一系列详细的技术规范文档，涵盖了协议的核心组件和算法实现。这些规范为开发者、研究人员和安全审计人员提供了深入理解 Aleo 协议的权威参考。

## Aleo VM 规范

Aleo 虚拟机（Aleo VM）规范描述了 Aleo 虚拟机协议的完整细节，包括核心算法和数据结构的设计与实现。

### DPC 方案

Aleo VM 基于 **DPC（Decentralized Private Computation，去中心化私有计算）** 方案构建。DPC 是一种创新的密码学框架，允许在保护数据隐私的同时验证计算的正确性。

### zk-SNARKs

Aleo 使用 **zk-SNARKs（Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge）** 技术生成简洁的零知识证明。这种技术使得验证者可以在不获取任何敏感信息的情况下，确认计算已被正确执行。

### 隐私与透明的设计权衡

Aleo 在隐私保护和系统透明性之间做出了精心设计的选择：

- **数据隐私**：交易不会揭示参与者的身份，也不会暴露交易的输入和输出数据。这确保了用户财务信息的完全保密性。
- **函数公开**：执行函数的身份是公开可见的。这是出于性能考虑的设计选择——公开函数身份可以显著优化证明生成和验证过程，同时仍然保护实际的交易数据。

### 核心数据结构

Aleo VM 规范定义了以下核心数据结构：

- **Account（账户）**：用户账户的完整规范，包括地址生成、密钥管理和账户状态。
- **Records（记录）**：Aleo 的状态表示模型，记录是加密的、仅所有者可读的数据单元，构成了 Aleo 私有状态的基础。

### 核心算法

Aleo VM 规范详细描述了以下关键算法：

- **虚拟机执行**：程序在 Aleo VM 中的执行流程和状态转换规则。
- **证明生成**：为程序执行生成零知识证明的完整过程。
- **验证**：验证零知识证明正确性的算法，确保证明者确实执行了声明的计算。

## AleoBFT 规范

AleoBFT 规范描述了 Aleo 共识机制的详细技术规范。AleoBFT 是 Aleo 网络达成状态一致的核心机制，确保所有节点对交易顺序和区块历史达成共识。
