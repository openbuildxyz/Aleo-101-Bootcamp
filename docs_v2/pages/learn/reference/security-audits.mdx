# 安全审计

Aleo 高度重视安全性，核心代码库（snarkOS 和 snarkVM）经过了全面的安全审计，以确保网络的稳健性和用户资产的安全。

## 独立第三方审计

Aleo 聘请了三家独立的顶级安全研究公司对核心代码库进行深度审计：

### 1. Trail of Bits

Trail of Bits 是一家专注于软件测试和区块链安全的知名安全研究公司。他们在智能合约安全、密码学实现和分布式系统安全方面拥有丰富经验。

### 2. NCC Group

NCC Group 是全球知名的网络安全公司，提供全面的安全咨询服务。他们的专业团队对区块链协议和加密系统有深入的理解和审计经验。

### 3. zkSecurity

zkSecurity 是零知识密码学安全领域的专家。鉴于 Aleo 大量依赖零知识证明技术，zkSecurity 的专业审计对于确保密码学实现的正确性至关重要。

## 审计周期

整个审计过程持续了 **超过 18 周**，确保了代码库的每个关键组件都经过了充分的审查和验证。

## 审计范围

### snarkOS 审计重点

snarkOS 是 Aleo 的网络层实现，审计重点关注以下方面：

- **Bullshark BFT 实现**：共识算法的正确性和安全性验证
- **节点间通信**：网络消息传递协议的安全性和健壮性
- **DoS 抵抗**：系统对拒绝服务攻击的防御能力评估

### snarkVM 审计重点

snarkVM 是 Aleo 的虚拟机实现，审计重点关注以下方面：

- **Synthesizer 和 Ledger 实现**：程序合成和账本状态管理的安全性
- **协议规范对齐**：实现与协议规范的一致性验证
- **数据序列化/反序列化**：数据编码解码过程的安全性，防止解析漏洞
- **交易和区块验证**：验证逻辑的正确性和完整性

## 审计结果

审计过程中发现的所有安全问题都已被识别并修复。Aleo 团队与安全审计公司紧密合作，确保每个发现的问题都得到了适当的处理和验证。

## 社区漏洞赏金计划

除了正式的第三方审计外，Aleo 还运行社区漏洞赏金计划（Bug Bounty），鼓励安全研究人员和社区成员参与发现潜在的安全问题。

### ARC-0041 审计竞赛

ARC-0041 审计竞赛由 **Sherlock** 主办，为社区安全专家提供了参与 Aleo 安全建设的机会。这类竞赛通过众包方式进一步增强了代码库的安全性。

## 审计报告

所有安全审计报告均在 GitHub 上公开获取，体现了 Aleo 对透明度和社区信任的承诺。开发者和安全研究人员可以查阅这些报告以了解审计的详细发现和修复情况。
